# Bashing

A collection of bash scripts, some useful, some not. Built while learning bash scripting.

| Script | What it does |
|---|---|
| `proxmaint.sh` | Proxmox maintenance: backups to USB, updates, ntfy notifications |
| `syscheck.sh` | Quick system health check |
| `listLargeFiles.sh` | Finds the largest files in a directory |
| `guessgame.sh` | Number guessing game |
| `trivia.sh` | Terminal trivia quiz |
